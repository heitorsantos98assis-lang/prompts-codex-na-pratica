# 10 Prompts Essenciais — Claude Code na Prática

## Como usar estes prompts

Cada prompt foi criado para funcionar com a stack da Bravy:

- **Frontend:** Next.js (App Router) → deploy na **Vercel**
- **Backend:** Node.js (Express) → deploy no **Coolify** (Hostinger)
- **Banco:** PostgreSQL → rodando direto no **Coolify**
- **Auth:** JWT (nunca use Supabase Auth)
- **UI:** Tremor, Cosmos UI, Origin UI + skill ui-ux-pro-max

## Instruções

1. Abra o Claude Code na pasta do seu projeto
2. Copie o prompt do arquivo correspondente
3. Cole no Claude Code e adapte as partes entre `[ ]`
4. O Claude vai executar — acompanhe e aprove as mudanças

| # | Categoria | O que faz |
|---|-----------|-----------|
| 01 | ARQUITETURA | Inicia o projeto do zero sem travar |
